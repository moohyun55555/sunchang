# 순창 청소년 자치배움터 탐험대

순창 창의예술미래공간(청소년 자치배움터·스포츠동·창의교육마당)을 블록 캐릭터로 돌아다니며 미리 둘러보는 3D 탐험 게임입니다.
설계도면(1~4층 평면도)과 층별 시안을 바탕으로 공간을 만들었고, 웹브라우저만 있으면 PC·태블릿·스마트폰에서 바로 할 수 있어요.

## 무엇을 할 수 있나요

- **탐험 도감**: 방에 들어가면 공간 소개 카드가 뜨고 도감에 기록돼요. 49곳을 모두 찾으면 임명장을 받아요.
- **확인 퀴즈 31개**: 층마다 5개 안팎이에요. 방 소개 카드에 나온 내용을 다시 확인하는 쉬운 3지선다예요(오답은 대부분 개그).
- **미니게임 8개 + 숨은 별**
  - 레고랜드: 레고 블록 쌓기
  - 댄스연습실: 리듬 댄스
  - 쿠킹클래스: 떡볶이 재료 받기
  - 코딩실: 로봇 길 찾기
  - 밴드연습실: 드럼 따라 치기
  - 롤러스케이트장: 쌩쌩 할아버지와 롤러 레이스
  - 풋살장: 승부차기
  - 실내클라이밍: 꼭대기 종 치기
  - 창의교육마당: 점프 블록 꼭대기의 별
- **층 이동 워프**: 엘리베이터와 계단 앞의 파란 빛기둥 발판을 밟으면(또는 F) 갈 층을 고를 수 있어요. 계단으로 가면 다른 층의 같은 계단에서 나타나요.
- **NPC 19명**: 건물 안팎을 돌아다니는 사람·동물에게 말을 걸면 재미있는 이야기를 들려줘요.
- **개그 장치**: 화장실 문, 크로마키 투명인간, 공연준비실 모자, 레고 밟기, 엘리베이터 안내 방송 등
- 진행 상황은 브라우저에 자동 저장돼요(메뉴 → 설정에서 처음부터 다시 하기 가능).

## 조작법

| | PC | 태블릿·폰 |
|---|---|---|
| 이동 | 방향키(또는 WASD) | 왼쪽 조이스틱 |
| 점프 | Space | 점프 버튼 |
| 말 걸기·액션 | F | F 버튼 |
| 카메라 | 마우스 드래그, 휠 확대 | 화면 드래그, 두 손가락 확대 |
| 지도 / 메뉴 | M / Esc | 화면 위 버튼 |

터치 화면이면 컨트롤러 모드가 자동으로 켜지고, 화면 위 게임패드 버튼으로 직접 켜고 끌 수도 있어요.

## 내용 고치기

글과 퀴즈는 모두 `js/data.js`에 모여 있어요. 코드를 몰라도 따옴표 안의 글만 바꾸면 됩니다.

- `QUIZZES`: 퀴즈 문제(`q`), 보기 3개(`opts`), 정답 번호(`a`, 0부터 시작), 해설(`why`)
- `SCENES`: 층별 방 이름(`name`)과 소개 글(`desc`), NPC 대사(`lines`), 개그 문구(`gags`)
- `OUTDOOR`: 바깥(창의교육마당) 구역과 NPC
- `GAMES`: 미니게임 이름, 설명, 별 기준

방 크기와 위치는 설계도(평면도)의 기둥 간격(6.6·7.2·7.8·7.2m)을 그대로 따른 미터 단위예요. 캐릭터는 실제 사람 키(약 1.6m)에 맞춰 두었어요. 화장실만 게임에서 둘러보기 편하게 설계도보다 작게 줄이고, 남은 자리는 엘리베이터 홀과 정수기 쉼터로 만들었어요.

## 직접 실행하기

빌드 과정이 없는 정적 웹페이지예요. 폴더에서 아무 웹서버나 켜면 됩니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 열어요. (`index.html`을 더블클릭하면 모듈 보안 정책 때문에 열리지 않아요.)

## 배포 (GitHub Pages)

1. 저장소 **Settings → General → Danger Zone → Change visibility → Make public** (무료 요금제에서는 공개 저장소만 Pages 사용 가능)
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch는 `main` / `/(root)` 선택 후 Save
3. 1~2분 뒤 `https://moohyun55555.github.io/sunchang/` 에서 열려요.
